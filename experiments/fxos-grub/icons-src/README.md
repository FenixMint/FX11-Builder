# Icon source files

These SVGs are editable source artwork for the FX OS GRUB prototype.

GRUB deployment assets should be rasterized to PNG, preserving the class-based filenames:

- `fedora.svg` → `icons/fedora.png`
- `windows.svg` → `icons/windows.png`
- `firmware.svg` → firmware/UEFI icon when the final class mapping is confirmed
- `os.svg` → generic fallback

Recommended source raster size: 128×128 or 256×256. The final GRUB theme should display them at approximately 48–56 px on the 1080p profile.

The icons are intentionally original FX artwork rather than copies of another distribution's theme assets.
