## Distribution policy

The ISO itself is deliberately **not committed to this public repository**. FX11 Builder's public distribution model is source code + build instructions + provenance + hashes. Users provide their own licensed Microsoft Windows installation media and build locally.

The repository `.gitignore` excludes `*.iso`, `*.wim`, and `*.esd` to reduce the risk of accidentally committing Microsoft installation binaries.

If private transfer of a test artifact is needed, use a private file-transfer/storage channel and verify the SHA-256 above after transfer. Do not treat a privately transferred test artifact as a public FX11 release.
